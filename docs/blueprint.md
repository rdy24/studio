# **App Name**: Voyage Control

## Core Features:

- Secure Login: User authentication and authorization using a secure login mechanism.
- Dashboard Overview: Display key metrics and summaries related to travel operations on a dashboard.
- User Management: Add, edit, and manage user accounts within the back office system.
- Role Management: Define and manage user roles with associated permissions to control access to different functionalities.
- shadcn UI Component Integration: Use 'shadcn ui' components (Datatable, Form, etc.) for consistent UI elements.
- Client-Side Rendering (CSR): Implement client-side rendering for all pages to improve performance and interactivity.
- Dark Mode Toggle: Enable users to switch between light and dark modes using a toggle switch.

## Style Guidelines:

- Primary color: Emerald Green (#4CAF50) to evoke a sense of adventure and nature, aligning with travel and exploration.
- Background color: Off-white (#FAFAFA) for a soft and clean aesthetic.
- Accent color: Golden Yellow (#FFC107) to highlight important elements and calls to action, conveying excitement and value.
- Body and headline font: 'Nunito' sans-serif for clear and accessible readability. Its rounded terminals give a friendly and approachable feel.
- Use consistent and professional icons from a library like Font Awesome or Material Icons, with a focus on travel-related imagery.
- Employ a clean, modern layout with clear separation of content sections using shadcn ui components to maintain visual consistency.
- Subtle animations for transitions and interactions to enhance user experience without being distracting, adding a touch of delight.
